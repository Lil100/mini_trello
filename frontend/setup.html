Mini Trello - Setup Guide

Backend URL: http://localhost:8080/api
Frontend URL: http://localhost:3000

Step 1: Start the Backend

Open a terminal and run:

cd backend
mvn spring-boot:run

You should see: Started MiniTrelloApplication in X seconds

Step 2: Start the Frontend

Open another terminal and run:

cd frontend
npx serve . -p 3000

Or if you have Python:

cd frontend
python -m http.server 3000

Step 3: Open the App

Go to: http://localhost:3000

Troubleshooting:
• Make sure port 8080 (backend) and 3000 (frontend) are not in use
• If you see “Failed to fetch”, check that backend is running
• Clear browser cache if you see stale content
• Check browser console (F12) for detailed errors
